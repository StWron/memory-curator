# 정제 규칙

1단계에서 판단보다 먼저 적용함. 각 줄은 조건, 처리, 막으려는 실패 순서. 모델이 바뀌면 "막으려는 실패"가 여전히 일어나는지 보고 지울지 정함.

## 삭제

- R1. 마감이 지났거나 끝난 일의 진행 상태 줄 → 삭제, 남은 결론만 유지 / 막는 실패: 끝난 일을 현재 상태로 착각
- R2. 대화나 저장소·문서에서 다시 알 수 있는 도구 사용법, 검색 결과, 명령어 → 삭제 / 막는 실패: 낡은 사용법이 최신 문서보다 우선됨
- R3. Claude에게 내린 작업 지시문(슬래시 명령과 인자, "정리해줘·지워줘·이렇게 해" 같은 일회성 요청) → 삭제, 새로 넣지도 않음 / 막는 실패: 지난 작업 지시가 다음 대화에서 사용자 성향처럼 다시 적용됨
  - 예외: 사용자가 "앞으로", "항상"처럼 지속을 명시한 형식·어조 선호는 preferences 후보로 넘김

## 이동

- R4. 특정 사람에 관한 관계 맥락 → 그 사람 파일로 이동 / 막는 실패: 사람 정보가 여러 프로젝트 파일에 흩어져 서로 어긋남

## 보류

- R5. Claude가 제안한 내용을 사용자의 결정처럼 적은 줄 → 보류로 넘겨 사용자에게 확인 / 막는 실패: 추천이 확정 사실로 굳음
