# memory-curator

Claude 메모리와 하네스(CLAUDE.md, 스킬, 훅)를 정기 정제 → 체계 재편 → 블라인드 검증 순서로 정리하는 플러그인.

- 명령: `/memory-curator`, `/mcur`
- 의존: 2단계(체계 재편)는 [Excelsus4/sfumato](https://github.com/Excelsus4/sfumato) 플러그인 필요. 없으면 2단계만 건너뜀
- 설치: 이 저장소를 마켓플레이스로 추가하거나 [StWron/claude-plugins](https://github.com/StWron/claude-plugins)에서 설치
